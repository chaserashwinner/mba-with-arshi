# MBA With Arshi — MBA Counselor Portfolio Website

An independent, high-performance portfolio website for **Arshi Khan — MBA Counselor**, featuring entrance exam guidance (CAT, XAT, CMAT, MAH CET, NMAT), B-school shortlisting tools, YouTube video reviews, and 1:1 guidance scheduling.

## Tech Stack

- **Framework**: Nuxt 3 (Vue 3, TypeScript)
- **Styling**: Tailwind CSS & CSS Variables
- **Architecture**: Decoupled content state (`data/portfolio.ts`), client-rendered SPA

## Setup & Development

```bash
# Install dependencies
npm install

# Start development server (http://localhost:3009)
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
